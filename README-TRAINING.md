**Open in Dev Spaces:** use your organization's Dev Spaces URL with this repository URL as the project source (see [DEVSPACE.md](./DEVSPACE.md) for context).

# Description

Short-form enablement for **platform engineers** installing the **OpenShift AI operator ecosystem** and **`DataScienceCluster`** on OpenShift 4 — the **Phase 0** prerequisite for the RHOAI 3.x modular journey (storage, registry, catalog, serving, MaaS).

# Objectives

After completing this training, you should be able to:

* Explain how **OLM**, the **OpenShift AI meta-operator**, and **`DataScienceCluster`** interact across control and execution planes.
* Install **Web Terminal**, **OpenShift AI**, **NFD**, **cert-manager**, **Connectivity Link**, and **Leader Worker Set** using declarative manifests.
* Configure a **selective** `DataScienceCluster` that enables dashboard, registry, and KServe while removing unused components.
* Verify **CSV**, **DSC phase**, and **gateway/MaaS dependency** health, and apply a short **troubleshooting** playbook for common failures.
